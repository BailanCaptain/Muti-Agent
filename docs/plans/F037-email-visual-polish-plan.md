# 日报邮件版视觉优化后续补丁（关联 F037）

## 目标与边界

F037 已经合入；本次不是重新实现或合入 F037，只优化其邮件 HTML 的视觉呈现，让真实邮件从“深色 Bento 卡片汤”变成层级更清楚、字号更易读的“暖白编辑部”版式。

保持不变：日报内容、publication 审核结果、筛选/排序/去重、四榜名称与上限、链接、主题、Markdown、发送与归档逻辑、网页端、运行时配置。

## 实施步骤

1. 以 `.runtime/daily-digest/2026-07-15/digest.html` 为只读基线，记录字节、颜色、字号、圆角，并生成桌面/窄屏截图。
2. 在 `renderer.test.ts` 增加稳定的视觉契约：暖白纸面、深墨刊头、陶土品牌线与高对比标题；先运行并确认 RED。
3. 只修改 `renderer.ts` 的邮件视觉 token 和 HTML 样式 helper：
   - 邮件纸面改为暖白编辑部风格，刊头保留最初原版的深墨构图并增加顶部品牌线；
   - 导览改为平面分栏，减少卡片套卡片；
   - 板块、子栏、焦点卡统一层级；
   - 正文提升到 14px，弱化重复强调色；
   - 圆角收敛到 12/16px，保持 table + inline CSS + 600px 上限。
4. 运行 renderer 定向测试，确保 publication、链接、ID、四榜和邮件兼容契约不变。
5. 使用 2026-07-15 同一归档数据只读重渲染到 `.agents/acceptance/F037-email-visual-polish/after.html`，不覆盖历史归档；生成桌面/窄屏截图。
6. 对比前后量化指标，验证最终 HTML 小于 98 KiB，并运行 API typecheck、lint、相关测试与独立验收。
