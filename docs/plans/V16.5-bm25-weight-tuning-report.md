## 决策

**保留 `DEFAULT_NAME_WEIGHT = 5.0`**（fts-provider 现默认）。

## 证据

### Fixture（11 wiki entities × 7 queries）

**期望命中 entities**（设计 / 文档类，name 含 entity ID）：
- `concepts/F011-backend-hardening-drizzle.md`
- `concepts/F021-context-window-resolver.md`
- `concepts/F018-session-bootstrap.md`
- `bugReport/B022-prompt-injection-redundancy.md`
- `concepts/F004-prompt-assembly.md`

**干扰 entities**（关键：name 完全不沾 query keyword，body 多次重复 query 词）：
- `concepts/db-driver-overview.md`（body 含 "drizzle drizzle drizzle"）
- `concepts/security-fundamentals.md`（body 含 "injection injection injection"）
- `concepts/agent-runtime-overview.md`（body 含 "session bootstrap session bootstrap"）

**Query 集**（设计原则：query 是关键词/短语而非 wiki 路径搜索；多数 query 仍会命中 entity name 中的 token，nameWeight benchmark 本就需要测 name token —— 范-r1 P3 修：不是"完全不命中 entity name 字面"）：

| # | Query | Expected Top |
|---|-------|--------------|
| 1 | drizzle migration | F011-backend-hardening-drizzle.md |
| 2 | context window resolver | F021-context-window-resolver.md |
| 3 | prompt injection | B022-prompt-injection-redundancy.md |
| 4 | backend hardening | F011-backend-hardening-drizzle.md |
| 5 | session bootstrap | F018-session-bootstrap.md |
| 6 | TOCTOU 防御 | F011-backend-hardening-drizzle.md（body 命中，name 不含） |
| 7 | rolling summary | F018-session-bootstrap.md（多 entity body 都含） |

### 矩阵结果（bodyWeight=1.0 固定）

| nameWeight | MRR    | Top-3 hit rate | 失败 query |
|-----------:|-------:|---------------:|------------|
|          1 | 0.786  | 90.0%          | drizzle migration → db-driver-overview / prompt injection → security-fundamentals / session bootstrap → agent-runtime-overview（3 失败） |
|          3 | 0.929  | 90.0%          | drizzle migration → db-driver-overview（仅 1 失败） |
|          5 | 0.929  | 90.0%          | 同 3（plateau） |
|          8 | 0.929  | 90.0%          | 同 3 |
|         10 | 0.929  | 90.0%          | 同 3 |
|         20 | 1.000  | 90.0%          | 全胜 |

### 决策推理

1. **weight=1 baseline 太弱**：3 个 hard query 干扰项胜出，MRR 0.786。
2. **weight=3 跨过 plateau**：MRR 跳 0.929（+18%），后续 5/8/10 完全相同。
3. **weight=20 边际收益**：仅多胜 "drizzle migration" 一个 query，MRR +8%。但：
   - 当前 fixture 11 entities 远小于真实 wiki（100k 量级），weight=20 可能 overfit
   - P11.b 接 LLM rerank 后 BM25 是 over-fetch（topK=20 → rerank 截 5），BM25 不是终排
   - body-only 命中 query 在 fixture 仅 1-2 个小样本（"TOCTOU 防御" + "rolling summary"），weight=20 在大规模下对此类 query 的反咬风险**未验证**（范-r1 P3 修：原表述"未实测"不准确，实际 7 query 都跑了，只是样本太少不能推大规模结论）
4. **5 是 plateau 中间值** — 减少调参敏感性，留 P11.b 接 hybrid 后用真 LLM rerank 修边角。

## Caveats

- Fixture 规模 11 entities 远小于真实 wiki（100k 量级），weight=20 的边际收益结论在大规模下未验证。
- `bodyWeight` 固定 1.0；name + body weight 联合调参留 P11.b 接真实数据后再说。
- LLM rerank（P15 接的 NoopReranker）一旦换成真实模型（Claude Haiku / Qwen），BM25 weight 重要性会进一步下降 —— BM25 的角色变成 over-fetch 候选池，不是终排。

## 后续动作

- ✅ **本 phase**：保留 `DEFAULT_NAME_WEIGHT = 5.0`，benchmark 测试归档到 `bm25-weight-tuning.test.ts` 作为 regression watch。
- ⏳ **P11.b 后**：用真实 docs/wiki 全集 reindex 跑同 benchmark，确认 5x 在 100k 量级仍合理；如未必再调。
- ⏳ **Phase 2 LLM rerank**：接真 LLM 后 weight=5 vs weight=3 差异可能完全消失，届时复测。
