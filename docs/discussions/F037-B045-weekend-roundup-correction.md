# F037 B045 周一栏目与失效信源纠偏讨论纪要

**日期**: 2026-07-27
**参与者**: 小孙、范德彪、Socrates、Parfit、Peirce
**上级入口**: [F037](../features/F037-daily-news-digest.md) · [B045](../bugReport/B045-weekend-roundup-section-regression.md)

## 背景

小孙查看 2026-07-27 实发后指出：“信源还是有失效的，而且栏目只剩 3 个了，博客和开源没了。”归档显示邮件只有 AI / 社区 / 热点，GitHub 四源未运行，Digg 仍为 429。

## 各方观点

- **范德彪**：B044 把“周一正文只取周末”扩大成“删除 GitHub 状态栏”，属于需求解释错误；时间范围与栏目结构必须解耦。
- **Socrates**：代码、测试与文档共同锁死错误合同。GitHub 是状态快照，不应套 `publishedAt` 日期门；非 GitHub 正文门仍须保留。
- **Parfit**：正常邮件有五类栏目；用户口述“博客”很可能指缺失的“播客速递”。官方 blog 源 10/10 健康但周末无新文，不能靠混入周五/周一正文制造存在感。周一应保留空播客的诚实栏目状态。
- **Peirce**：Digg 当前是 Vercel WAF challenge，持续 429、无 `Retry-After`，历史可靠率 14/21；继续重试或换出口属于绕限制，不是恢复。Lobsters 官方 `/t/ai.rss` 当前 200、25 条，现有 parser 25/25 可解析，且社区审核质量优于 DEV AI tag feed。

## 共识

1. 周六、周日继续停发。
2. 周一 AI / 社区 / 热点 / 播客正文仍严格只取上海时区周六、周日。
3. GitHub 四榜作为“截至周一的开源榜单快照”照常抓取、准入、排序和展示；它仍不能独自满足日报非空门。
4. 周一邮件、Markdown 与网页版固定保留正常五栏骨架；无周末播客时显示“本周末暂无新节目”，不伪造条目。因邮件密度隐藏已批准速览时明确说明，不误报“暂无”。
5. 官方 blog 源继续正常运行；周末无新文是 healthy-empty，不放宽日期门。
6. Digg 从运行清单退休，以 `lobsters-ai → https://lobste.rs/t/ai.rss` 等量替换。

## 分歧与决断

- **空播客栏继续隐藏，还是显示空态？** 既有行为是“无新集则隐藏”，但这次用户直接反馈栏目缩成三栏。决定仅在周一周末速览保留空态，周二至周五不改。
- **Digg 再加挑战绕过，还是替换？** 否决绕过；WAF challenge 与私有 RSC 漂移都不适合作为长期生产源。
- **DEV AI feed 还是 Lobsters？** DEV 更新更多但自促与标签滥用明显；选择信号更干净、公开 RSS 合同明确的 Lobsters。
- **为补博客内容放宽到周五/周一？** 否决；这会违背“周一只是整合周末”。

## 行动项

1. RED 锁定周一 GitHub 四源运行、五栏空态与 GitHub-only fail-closed。
2. RED 锁定运行清单不含 Digg、包含 Lobsters，数量守恒且 RSS 可解析。
3. 修正 F037 AC26/D21、信源主表和 B045 六件套。
4. 门禁、独立验收、review 通过后生成并发送修正版。

## 收敛检查

1. 否决理由 → ADR？没有；否决记录已在本纪要，未产生新的架构决策。
2. 踩坑教训 → lessons-learned？有，已追加“时间范围约束不得隐式删除栏目”。
3. 操作规则 → 指引文件？没有；现有愿景对照流程足够，属于执行未遵守。
